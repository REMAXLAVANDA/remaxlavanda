# Kurul Geri Bildirimleri

Her /kurul raporundan sonra yanlış, eksik veya gereksiz bulguları buraya yaz. Kısa olması yeterli.

Şablon:
```
## [tarih] - [rapor adı]
- Ajan: gorsel-denetci
- Bulgu: "İptal butonu kırmızı" uyarısı
- Tür: yanlış alarm / kaçırılan / alan dışı / yanlış standart / tekrar
- Doğrusu: Bizde sil ve iptal butonları bilerek kırmızı.
- Durum: İşlenmedi
```
